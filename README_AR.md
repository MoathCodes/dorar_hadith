# مكتبة الدرر السنية للحديث

[English](README.md)

حزمة Dart للبحث في أحاديث الدرر السنية وقراءة الشروح والروايات المرتبطة والتصنيفات الموضوعية وخيارات المراجع المحلية. تعمل الحزمة الأساسية دون Flutter، وتستخدم تطبيقات Flutter حزمة `dorar_hadith_flutter`.

يتطلب الإصدار 0.6.0 نسخة Dart 3.13.0 أو أحدث. وتتطلب حزمة Flutter نسخة Flutter 3.47.5 أو أحدث. اقرأ دليل الانتقال قبل الترقية من 0.5.x.

## التثبيت

ثبّت الحزمة الأساسية لاستخدامها مع Dart:

```sh
dart pub add dorar_hadith
```

```dart
import 'package:dorar_hadith/dorar_hadith.dart';

Future<void> main() async {
  await DorarClient.use((client) async {
    final results = await client.searchHadithDetailed(
      const HadithSearchParams(
        value: 'الصلاة',
        types: {HadithTypeFilter.qudsi},
      ),
    );
    for (final record in results.data) {
      print('${record.hadithId}: ${record.hadith}');
      print('${record.book} | ${record.numberOrPage} | ${record.grade}');
    }
  });
}
```

في Flutter، ثبّت `dorar_hadith_flutter` وهيّئها قبل إنشاء العميل:

```dart
WidgetsFlutterBinding.ensureInitialized();
await DorarHadithFlutter.ensureInitialized();
```

تُحمّل حزمة Flutter ملفات الحزمة الأساسية تلقائيًا، لذلك لا تحتاج إلى إضافتها إلى `pubspec.yaml` الخاص بتطبيقك. تحفظ نسخ المراجع التي تحققت من سلامتها في مجلد دعم التطبيق، وتحفظ ذاكرة API المؤقتة القابلة للكتابة في قاعدة بيانات مستقلة.

## اختيار طريقة البحث

| الطريقة                               | النتيجة                                                                 | الصفحات                                                   |
| ------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------- |
| `client.searchHadith(params)`         | نتائج API السريع في سجلات `Hadith` مختصرة                               | عادةً 15 نتيجة في الصفحة؛ العدد الكلي غير معروف           |
| `client.searchHadithDetailed(params)` | سجلات `DetailedHadith` بالمعرفات والمصادر والتصنيفات والروابط المعلنة   | 30 نتيجة لكل تبويب؛ البحث العادي يسمح بعشر صفحات كحد أقصى |
| `client.sharh.search(params)`         | الشروح الكاملة المرتبطة بالأحاديث المطابقة، مع حفظ علاقة كل حديث بالشرح | يستخدم البحث العادي في الأحاديث                           |
| `client.searchSharhText(params)`      | مقتطفات `SharhSnippet` من نتائج البحث داخل نص الشرح                     | 15 نتيجة في الصفحة؛ الصفحات اللاحقة تستخدم استجابة AJAX   |
| `client.categories.browse(params)`    | أحاديث ضمن تصنيف موضوعي                                                 | 20 نتيجة لكل تبويب؛ له حد مستقل عن البحث العادي           |

يعرض `SearchCapabilities.quick` و`.detailed` الخيارات المدعومة. امتلاء صفحة البحث السريع أو البحث في الشرح يشير إلى احتمال وجود صفحة أخرى، لكنه لا يثبت ذلك. اقرأ `metadata.pagination.nextPageEvidence` واترك العدد الكلي المجهول بقيمة null.

يقبل البحث التفصيلي:

- `types` و`sort: HadithSort.degree` وما يصل إلى أربع عبارات `optionalPhrases` مرتبة.
- طريقة البحث والكلمات المستبعدة والدرجات والمحدثين والكتب وخيارات الرواة.
- `specialist` لاختيار تبويب `متخصص` في الدرر. هذا اختيار تبويب، وليس نوعًا للحديث.

يمكن ترك عبارة البحث الأساسية فارغة إذا وُجدت عبارة إضافية غير فارغة. تحتفظ الخانات الفارغة بمواقعها بين العبارات.

يقبل البحث السريع النص والصفحة ونطاقي الأحاديث القدسية وآثار الصحابة اللذين تحققنا منهما، وطريقة البحث والكلمات المستبعدة والدرجات والمحدثين والكتب. ويرفض قبل إرسال الطلب تعدد النطاقات ونطاق الأحاديث ذات الشرح والعبارات الإضافية والترتيب والتبويب المتخصص ونطاق المرفوع ومعرفات خيارات الرواة. استخدم البحث التفصيلي لهذه الخيارات.

`zone` هو الخيار القديم لتحديد نطاق البحث العادي. استخدم `zone` أو `types` منفردًا. يُرفض `SearchZone.sharh`؛ استخدم هذه الطريقة للبحث داخل نص الشرح:

```dart
final snippets = await client.searchSharhText(
  const SharhTextSearchParams(value: 'النية', page: 1),
);
final explanation = await client.sharh.getById(snippets.data.first.id);
```

## المعرفات والخيارات المكتشفة

معرفات الأحاديث والشروح والكتب والمحدثين وخيارات الرواة والتصنيفات أنواع مستقلة. `HadithRecordId('2065')` و`SharhId('2065')` معرفان مختلفان. يحتفظ JSON بقيمهما النصية الأصلية، وتظل الطرق التي تقبل معرفات نصية متاحة.

استخدم المعرفات ذات الأنواع المحددة عند اختيار نتائج خدمات المراجع:

```dart
final scholars = await client.searchMohdith('البخاري');
final books = await client.referenceDiscovery.getBooksForScholars(
  [scholars.first.typedId],
);
final results = await client.searchHadithDetailed(HadithSearchParams(
  value: 'الصيام',
  scholarIds: [scholars.first.typedId],
  bookIds: [BookId(books.data.first.id)],
));
```

تحل `scholarIds` و`bookIds` و`narratorChoiceIds` محل قوائم `mohdith` و`books` و`rawi` القديمة المقابلة لها. اختر تمثيلًا واحدًا لكل مرشح. تُحذف المعرفات المكررة وتُرتب عند بناء الطلب.

الكتب التي تُعاد للمحدثين هي مصادر مرتبطة بأحكامهم على الأحاديث، ولا تعني بالضرورة أنهم ألّفوها. تحتفظ بيانات النتيجة بمعرفات المحدثين المحددين، وتصف التغطية بأنها قائمة الخيارات الحالية.

الإكمال التلقائي لأسماء الرواة يرسل طلبًا عبر الشبكة، وتغطيته جزئية:

```dart
final choices = await client.referenceDiscovery.searchNarratorChoices('أبو هريرة');
// Each ID is a filter choice; compound labels and aliases are not person identities.
```

## الأحاديث المرتبطة وأسباب الورود

```dart
final alternatives = await client.getAlternates('i9N1PTUu');
final similar = await client.getSimilarResult('i9N1PTUu');
final circumstances = await client.getAsbab('wcyAMgeR');
final sources = await client.hadith.getUsul('j0j8uiR3');
```

تفصل نتائج المجموعات الحديث المطلوب عن السجلات المرتبطة به، وتحفظ ترتيبها في المصدر. يعيد `getAlternates` جميع البدائل. أما `getAlternate` القديم فيعيد البديل الأول، أو null إذا تعرّف المحلل على مجموعة فارغة.

يحافظ `getSimilar` على سلوكه السابق، فيضم الحديث المطلوب إلى القائمة. استخدم `getSimilarResult` للحصول على الحديث الأصلي والأحاديث المرتبطة بصورة منفصلة.

التحليل الصارم هو الوضع الافتراضي. فشل الطلب أو تخطيط الصفحة غير المعروف أو السجل غير السليم يؤدي إلى استثناء ذي نوع محدد. اختر `ParsePolicy.bestEffort` للاحتفاظ بالسجلات السليمة والحصول على أعداد المرشحين والمحللين والمتجاوزين وتحذيرات محدودة العدد. يمكن أن يكون الحديث الأصلي في نتيجته null إذا تعذر تحديد هوية الحديث المطلوب؛ وتبقى السجلات الملتبسة ضمن النتيجة.

تصف الحالات (`advertised` و`notAdvertised` و`unknown`) ما تعلنه صفحة المصدر من إمكانات، وهي مستقلة عن نجاح الطلب اللاحق. طلب الأصول أو أسباب الورود لا يضيف إعلانًا عن توفرها. تحتفظ كل رواية سياقية بمحدثها وحكمها وموضعها الخاص.

## نص الشرح وتنسيقه الآمن

`Sharh.hadith` هو سجل `DetailedHadith` مأخوذ من رأس صفحة الشرح. ويحفظ `Sharh.embeddedHadith` الرواية ذات المصدر المستقل داخل الشرح عندما تتوفر بياناتها. أما `Sharh.document` فيحفظ نص الشرح وHTML المصدر وأجزاء النص والتعليقات المرتبطة به.

```dart
final explanation = await client.sharh.getById('137940');
final document = explanation.document!;
print(document.commentaryText);             // excludes embedded narration/citation
final safeHtml = renderDocumentHtml(document);
final tokens = documentRenderTokens(document);
```

تميز أجزاء النص بين الرواية وبيانات المصدر والشرح والإسناد والفقرة والعنوان وعنصر القائمة والفاصل. وتحفظ التعليقات كل ورود للفظ مُعرّف ومعناه، وعنوان الرابط ووجهته، وروابط القرآن التي يحددها المصدر، ونطاقات الاقتباس المحايدة.

تُقاس النطاقات بإزاحات UTF-16 نصف مفتوحة في `sourceText`: تبدأ بالموضع المحدد وتشمل بدايته، وتنتهي قبل موضع النهاية. احسبها على نص المصدر، لا على النص المطبع للبحث.

يحتفظ `quranReference` بعنوان الرابط الأصلي. تُستخرج من العناوين المعروفة تسمية السورة وقائمة الآيات؛ ويظل معرف السورة الرقمي مجهولًا دون ربط متحقق منه. لا تُستخدم أرقام رابط التفسير كمعرفات للآيات. وتحتفظ `Citation` و`Verdict` و`ParsedLocator` بألفاظ المصدر. لا يضيف المحلل تصنيفًا تلقائيًا للحكم أو شبكة لهويات الرواة.

تحفظ نصوص المصدر الألفاظ وعلامات الترقيم والتشكيل وعلامات اتجاه الكتابة. يزيل العرض النصي القديم رقم النتيجة في البداية فقط عندما يُتحقق من كونه رقم عرض، ويحفظ حدود الفقرات. يعيد `removeHtml: false` وسوم المصدر المحفوظة. استخدم `renderDocumentHtml` لتضمين HTML مُهَرّب ومحكوم بعناصر مسموحة. تستخدم تلميحات الألفاظ تعريفات نصية مُهَرّبة، ويبقى HTML التعريف الأصلي متاحًا بصورة مستقلة.

## نسبة الكلام إلى قائله

يمكن الاستفادة من الوسوم البنيوية التي يوفرها المصدر في التنسيق. لكن اسم الراوي أو المحدث صاحب الحكم أو علامة الاقتباس أو لون CSS أو كلمة `قال` وحدها لا تحدد بصورة موثوقة ألفاظ المتكلم وحدودها.

يترك التحليل الافتراضي هوية المتكلم غير مؤكدة، ويعرض الاقتباسات بتنسيق محايد. استورد التعليقات التي خضعت للمراجعة بصورة مستقلة:

```dart
// Load an annotation produced by a trusted review process for this source.
final reviewed = AttributionAnnotation.fromJson(reviewedJson);
document.validateAttributions([reviewed]);
final tokens = documentRenderTokens(document, reviewedAttributions: [reviewed]);
```

يتحقق المحلل من بصمة النص ورابط المصدر والدليل وبيانات المراجع ونطاق النص. ويرفض البصمات القديمة والنطاقات خارج النص أو التي تقسم زوجًا بديلًا في UTF-16، ونقص دليل المراجعة، والتعارض بين نسب مؤكدة. لا تنتج الإشارات التخمينّية تنسيقًا ينسب الكلام إلى متكلم مؤكد. وتبقى صحة النسبة نفسها مسؤولية عملية المراجعة.

## التصنيفات الموضوعية

```dart
final roots = await client.categories.getRoots();
final children = await client.categories.getChildren(roots.data.first.selector);
final matches = await client.categories.search('الصلاة');
final page = await client.categories.browse(CategoryBrowseParams(
  categoryId: CategoryId(matches.data.first.id),
  page: 11,
));
```

تحتفظ محددات التصنيفات العليا بقيمها الأصلية كاملة، بما فيها المسافات المؤثرة في نهاية القيمة. معرفات التصنيفات الفرعية نصوص لا نفترض بنية داخلية لها. تعرض هذه الطرق التصنيفات التي رصدناها، ولا تدّعي إعادة بناء شجرة كاملة لها.

## المراجع المحلية وترقيتها

يسجل `assets/data/reference_manifest.json` إصدار النسخة ومخطط قاعدة البيانات وإصدار تطبيع البحث والأعداد والبصمات ولقطات المصدر وطريقة الجمع والتغطية.

تعمل خيارات الكتب والمحدثين الحالية دون شبكة. وتبقى معرفات المحدثين التاريخية متاحة عند البحث بالمعرف، مع استبعادها من التصفح الافتراضي. تحتفظ الأسماء المتغيرة بتسمياتها السابقة كأسماء بديلة للبحث.

تجمع خيارات الرواة نسخة تاريخية مع عينات من نتائج الإكمال التلقائي الحالية. تغطيتها جزئية. يحتفظ `RawiItem.name` بالتسمية الأصلية، بينما يمثل `normalized_value` في المخطط 2 مفتاح بحث مستقلًا. يطبق البحث والعد تطبيعًا عربيًا واحدًا، ويعامل `%` و`_` الحرفيين كما هما، ويرتب النتائج بالمعرف. تطبيع البحث لا يغير نص العرض.

في Dart الأصلي، تُقرأ ملفات المراجع الثابتة بالنسبة إلى الحزمة المثبتة، بغض النظر عن مجلد العمل. وتُحفظ الذاكرة المؤقتة القابلة للكتابة افتراضيًا في `cache.db` داخل مجلد العمل؛ اضبط اتصالًا مخصصًا لها عند الحاجة. يستخدم Flutter الأصلي مجلد دعم التطبيق ونسخًا ذات إصدارات جرى التحقق منها، ويحفظ ملفات المراجع والذاكرة المؤقتة القديمة. وفي المتصفح، تكون لكل نسخة مرجع هوية قاعدة بيانات خاصة بها.

تحتاج قواعد بيانات الرواة المخصصة إلى المخطط 2. أنشئ ملفًا جديدًا عند الترحيل:

```dart
await migrateReferenceDatabase(inputPath: 'custom-v1.db', outputPath: 'custom-v2.db');
// Configure your connection to the verified copy. The input remains untouched.
```

## الإعداد في المتصفح

قدّم ملفي `sqlite3.wasm` و`drift_worker.dart.js` المتوافقين عند عنوان تطبيقك الأساسي. يشرح [مثال Flutter](https://github.com/MoathCodes/dorar_hadith/blob/main/dorar_hadith_flutter/example/README.md) خطوات الإعداد.

أكد الاختبار من متصفح يعمل على localhost أن الدرر يمنع استجابات الموقع وAPI السريع المباشرة بسبب CORS. التهيئة المحلية لا تتصل بالدرر. للطلبات عبر الشبكة، مرّر `http.Client` يوجه الطلبات عبر خادم تملكه:

```dart
final client = DorarClient(
  httpClient: DorarHttpClient(client: yourHttpClient),
);
```

`yourHttpClient` هو وسيلة النقل الخاصة بتطبيقك. لا توفر الحزمة خادمًا وسيطًا عامًا. وتظل أخطاء النقل ظاهرة في صورة استثناءات.

## الذاكرة المؤقتة والأخطاء

تحفظ الخدمات الاستجابات الخام التي تحققت من بنيتها بتنسيق الذاكرة المؤقتة 3، ثم تحلل كل طلب وتعرضه محليًا. يمكن لطلبات النص وHTML والمستند مشاركة الاستجابة دون خلط نماذج النتائج. تشمل مفاتيح الذاكرة المؤقتة المسار والمضيف والرابط الموحد والخيارات التي تغير الاستجابة. وتحفظ الاستجابة بصمتها وحالتها ونوع المحتوى والترميز ووقت الجلب والرابط النهائي عندما توفره وسيلة النقل.

يُحذف الإدخال التالف وتُجلب الاستجابة مجددًا. تُرفض صفحات التحقق غير المعروفة بدل تخزينها كأنها نتائج فارغة. وتُتجاهل نطاقات الذاكرة المؤقتة القديمة دون إعادة ضبط SQLite.

القيم الافتراضية هي 100 إدخال في الذاكرة و750 صفًا في SQLite وصلاحية سبعة أيام. تستخدم تفاصيل الشروح والمحدثين صلاحية 30 يومًا.

يحدد `DorarSubrequestException` فشل جلب شرح مرتبط، ويحفظ `DorarException` الأصلي في `cause`. وتحتفظ أخطاء الشبكة والمهلة وحد الطلبات والتحقق وعدم العثور والتحليل بأنواعها. استدعِ `dispose()` عند الانتهاء، أو استخدم `DorarClient.use` لإغلاق العملاء وقواعد البيانات تلقائيًا.

## التطوير والنشر

استخدم FVM لتشغيل أوامر Dart وFlutter في المستودع. تستخدم الاختبارات المعتادة استجابات محفوظة وتعمل دون شبكة. جمع لقطات المصدر وتحديث المراجع عمليتان صريحتان أثناء التطوير. وتُستبعد بيانات الاختبارات والأدوات من ملفات النشر في pub.

اقرأ [دليل الانتقال](doc/MIGRATION_0_6_0.md) عند الترقية من 0.5.x، و[دليل النشر](doc/RELEASE_0_6_0.md) عند تجهيز رفع الحزمة. يربط [سجل التنفيذ](https://github.com/MoathCodes/dorar_hadith/blob/main/docs/DORAR_0_6_0_IMPLEMENTATION_STATUS.md) التدقيق بالاختبارات ونتائج المنصات. ويبقى تحديث تطبيق Tawaq مهمة مستقلة.
